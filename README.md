# 📉 Customer Retention & Churn Analysis Dashboard (Power BI)

## 📌 Project Overview
This project presents an **interactive Power BI dashboard** focused on analyzing **customer churn behavior and retention drivers**.  
The dashboard helps businesses understand **why customers leave**, **which segments are most at risk**, and **what factors improve customer retention**.

---

## 📊 Key Metrics
- **Total Customers:** 7,043  
- **Churned Customers:** 1,869  
- **Churn Rate:** 27%  
- **Average Customer Tenure:** 32.37 months  

---

## 🔍 Dashboard Insights

### 🔴 Churn Overview
- Visual breakdown of **churned vs retained customers**
- KPI cards highlighting customer base health

### 📑 Contract & Payment Analysis
- **Month-to-month contracts** show the highest churn rate
- **Two-year contracts** have the best retention
- Customers using **Electronic Check** payment method churn the most

### 🌐 Service-Based Churn Patterns
- Higher churn observed in **Fiber Optic** and **DSL** internet services
- Customers without **Online Security** and **Tech Support** are more likely to churn

### ⏳ Tenure-Based Analysis
- New customers (0–1 year) show the highest churn
- Long-term customers (4+ years) have strong retention rates

### 💰 Revenue Impact
- Churned customers have **higher average monthly charges**
- Retained customers provide stable long-term value
